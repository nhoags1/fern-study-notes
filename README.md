# Fern Study Notes

My CS study notes as one web page, looked after by Fern. Each subject has a
guide, a quick reference, vocab and resources. Every card gives the main idea
first, and opens for the details and code.

## Run it

No build step and nothing to install. Open `index.html` in a browser.

It needs the internet only for the fonts. "Got it" ticks, notes and the
light/dark choice are saved in that browser only.

## Folder layout

| Path | What it is |
|---|---|
| `index.html` | The page and its styles |
| `app.js` | The subject list, tabs, search, progress and theme |
| `data/java.js`, `terminal.js`, `git.js`, `software-engineering.js`, `ai.js`, `python.js` | The notes, one file per subject |

On my Mac only (listed in `.gitignore`, not on GitHub): `drafts/`,
`ai-expansion-review.md`, `AGENTS.md` and the `.zip` downloads.
